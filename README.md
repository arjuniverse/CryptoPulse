# 🚀 CryptoPulse



## ⚙️ Setup

Clone the repository and install dependencies:

```bash
git clone https://github.com/arjuniverse/SpendWise.git
cd SpendWise
npm install
npm run dev
```

Open your browser :
```
http://localhost:5173
```

---

## 🏗️ Build

To create a production build:

```bash
npm run build
```
